토큰 발급 방법 (최초 1회)
  1. GitHub → Fine-grained token 생성 페이지로 이동 (kimkuksung 계정으로 로그인)
  2. Repository access: Only select repositories → kimkuksung.github.io
  3. Permissions → Repository permissions → Contents: Read and write
  4. 생성된 토큰을 위 입력칸에 붙여넣고 불러오기

토큰은 이 브라우저에만 저장되며 GitHub API(api.github.com) 외에는 전송되지 않습니다. 공용 PC에서는 "기억"을 체크하지 마세요.
